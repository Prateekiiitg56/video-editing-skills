# Style: Meme / Comedy

Load with: `editing-foundations`, `sound-design`, `captions-typography`, `ffmpeg-pipeline`.

## Signature

- Setup fast, punchline clean. Cut **right after** the punchline lands (0.3-0.8 s reaction), or hold an awkward pause on purpose.
- Visual punctuation: crash zoom (100 → 150% in 2-4 frames) on reactions, freeze frame + record scratch, slow-mo of the "fail".
- POV text at the top ("POV: it's 2 AM and the bug is 'fixed'"), short, lowercase or sentence case.
- SFX are part of the joke: vine boom, record scratch, bonk, sad trombone, laugh track — sparingly and on the exact frame.
- Smash cuts between contrasting moods ("my two moods": calm → chaos).
- Loops: end frame connects to the start for rewatches.

## Timing rules

- Comedy is timing: cut on the frame the reaction peaks; 2 frames late kills it.
- Rule of three: two normal beats, third breaks the pattern.
- Silence before the punchline (duck music fully for 0.3-0.5 s).
- Don't explain the joke with text that repeats what we see.

## Recipe

1. Write it as setup / escalation / punchline / button.
2. Rough cut on dialogue or action; trim everything that isn't setup or payoff.
3. Add text (POV/context) for the first 2-3 s.
4. Place zooms/freezes on reactions; SFX aligned to frames (start file `attack` earlier).
5. Music: trending/meme audio added in-app if licensed only there; otherwise royalty-free.

## Dev / niche humor notes

Works best when the specific detail is accurate (real error messages, real IDE, real commit messages). Never fake screenshots of real people or companies.
